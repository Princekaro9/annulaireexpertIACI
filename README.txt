IVOIRE AI DIRECTORY

Page d’annuaire responsive réalisée en HTML, CSS et JavaScript, sans installation nécessaire.

Pour l’ouvrir : double-cliquez sur index.html dans l’Explorateur de fichiers. La police Manrope/DM Sans se charge depuis Google Fonts si Internet est disponible. L’illustration principale est conservée dans assets/fond-ivoire-ai.png.

Fonctionnalités incluses
- Recherche sur les noms, les organisations, les fonctions, les domaines et les biographies.
- Filtres par type de profil, domaine et profils certifiés, avec réinitialisation.
- Affichage progressif des profils par groupes de six.
- Fiche détaillée de chaque profil.
- FAQ en accordéon.
- Formulaire de proposition avec validation des champs et consentement.

Les 12 profils actuellement inclus sont des exemples éditoriaux pour la maquette. Le formulaire confirme localement la saisie et ne transmet ni ne stocke de données. Vérifier les biographies, les sources, les droits des portraits et les mentions légales avant publication.
